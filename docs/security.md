# セキュリティ・安全設計

| 項目 | 実装 |
|---|---|
| 最小権限 | GUI・デーモンとも一般ユーザーで動作。インストーラは root 実行を拒否し、apt での依存導入だけ内容を表示して確認後に sudo を使う。マウント/アンマウントは UDisks2 + Polkit（アクティブセッションの既定ポリシー）。汎用 `sudo mount` は使わない |
| 元メディア | 読み取り専用・`O_NOFOLLOW` でのみオープン。UDisks2 でのマウントは `ro,nosuid,nodev,noexec`。自動実行ファイルやスクリプトは実行しない |
| 対象外デバイス | USB/SD(sdio)/リムーバブル以外、`/`・`/boot`・`/home`・`/usr`・`/var`・スワップ・ステージング領域を含むドライブは自動除外 |
| NAS 資格情報 | Secret Service（gnome-keyring）に保存。`gio mount` へは標準入力で渡し、引数・環境変数・ログに出さない。URL にユーザー情報を含めることは設定検証で拒否 |
| 共有のすり替え | 保存先ルートの識別ファイル（target marker）を毎回照合。`mounted_path` はルート FS・ステージングと同じデバイスなら転送しない |
| SMB | GVfs/CIFS の既定（SMB2 以上）を使用。SMB1 を有効にする設定は持たない |
| パス | 相対パスは `..`・絶対パス・空要素・NUL を拒否。格納名は予約文字・予約名・末尾ドット/空白を置換し、NFC + 大文字小文字非区別で衝突回避。復元時もマニフェストを再検証し、既存ファイルを上書きしない |
| SSD 削除 | `sessions/<UUID>` のみ。シンボリックリンク・所有者・マウント境界・他プロセスのオープン（/proc/*/fd）を確認してから削除。`remove_dir_all` は symlink を辿らない |
| IPC | `$XDG_RUNTIME_DIR/sd-backup-manager`（0700）上の 0600 ソケット + 接続ごとの peer UID 照合。1 メッセージ 16MiB 上限 |
| ログ | パスワード等のキーワードを含む行・URL の userinfo を伏せ字にしてエクスポート。撮影ファイルの内容はログに記録しない |
| 配布 | GitHub Release の成果物は SHA256SUMS で照合してから展開。CI で `cargo audit` と `--locked` ビルドを実施 |

## 既知の限界

- NAS の読み戻しハッシュ一致は、NAS 装置の電源断・故障に対する永続化を 100% 保証しません。
  NAS 側のスナップショットや別媒体へのバックアップを併用してください。
- SSD は一時保存先で、NAS 転送完了後に削除されます。これは 3-2-1 バックアップではありません。
- GNOME の自動マウントが先に読み書き可能でマウントした場合、そのマウントを利用します
  （アプリ自身は読み込み専用でしかアクセスしません）。
